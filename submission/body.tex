\section*{Data availability}
All data, code and results needed to reproduce every number, figure and table in this article are
publicly available at \url{https://github.com/Kendiukhov/streaming-quasi-newton-dependent-data}.
The repository contains the estimator, the experiment scripts, the saved result files from which
every reported number is generated, and the tests that validate the closed-form population
quantities. The two real data sets are third-party and are not redistributed; they are downloaded
from the UCI Machine Learning Repository by the script \texttt{experiments/fetch\_data.py} and are
cited as \citet{hogue2019metro} and \citet{chen2019beijingairuci}.
