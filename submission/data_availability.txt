Data availability statement

Information Sciences applies Option C of Elsevier's research data guidelines: data should be
deposited in a repository, and cited and linked from the article. This is satisfied -- the
code and results are archived on Zenodo with a DOI, and cited in the reference list as a
software reference.

Statement to enter in the submission system:

  All code, saved results and derived data needed to reproduce every number, figure and table
  in this article are archived on Zenodo. The release used to produce the results reported
  here is:

    Kendiukhov, I. (2026). Streaming inversion-free quasi-Newton estimation and inference on
    dependent data (version release1) [Software]. Zenodo.
    https://doi.org/10.5281/zenodo.21891313

  The concept DOI https://doi.org/10.5281/zenodo.21891312 always resolves to the most recent
  release, and development continues at
  https://github.com/Kendiukhov/streaming-quasi-newton-dependent-data

  The archive contains the estimator, the experiment scripts, the result files from which every
  reported number is generated, and the tests that validate every closed-form population
  quantity against long simulation.

  The two real data sets analysed are third-party and are not redistributed. They are
  downloaded from the UCI Machine Learning Repository by experiments/fetch_data.py and are
  cited in the reference list:

    Metro Interstate Traffic Volume, UCI Machine Learning Repository,
      https://doi.org/10.24432/C5X60B
    Beijing Multi-Site Air Quality, UCI Machine Learning Repository,
      https://doi.org/10.24432/C5RK5G

Which DOI to give the journal: use the VERSION DOI (...313) wherever the point is
reproducibility of the results in this article, which is what the manuscript does. Use the
CONCEPT DOI (...312) when the point is the software as an ongoing project. The manuscript's
Data availability section gives both and says which is which.
